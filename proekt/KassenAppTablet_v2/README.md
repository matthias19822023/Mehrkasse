# KassenAppTablet v2

Android-Tablet-Kassenprogramm im Querformat.

## Funktionen
- 8 große Kassenkacheln in einem 4x2-Raster
- Artikel aktivieren/deaktivieren
- Bezeichnung, Preis und Farbe
- jeder Tastendruck = 1
- aktuelle Summe
- Übergabe mit Datum/Uhrzeit
- detaillierte Übergabeübersicht
- Hintergrundauswertung je Artikel
- CSV-Export, direkt mit Excel öffnbar
- Auswertung zurücksetzen
- PIN-Schutz für Einstellungen
- PIN ändern
- lokale Room-Datenbank, kein Internet erforderlich

## Standard-PIN
1234

Die PIN sollte nach dem ersten Start unter Einstellungen geändert werden.

## Installation
Projekt in Android Studio öffnen, Gradle synchronisieren und mit einem Android-Tablet starten.
Für eine APK: Build > Build APK(s).
